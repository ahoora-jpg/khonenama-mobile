# Product Spec — Barber / Salon SaaS

## هدف

یک اپلیکیشن فارسی، RTL و mobile-first برای نوبت‌دهی آرایشگاه و سالن که از ابتدا به‌صورت multi-tenant / white-label طراحی شود و همان هسته بدون بازنویسی به سالن‌های دیگر فروخته شود.

## نقش‌ها

- Super Admin: ساخت/فعال/تعلیق سالن، subscription و تنظیمات پلتفرم
- Salon Owner: پروفایل، برند، ساعات، تعطیلات، خدمات، پرسنل، مشتریان، نوبت‌ها، اخبار، گالری و اعلان‌ها
- Staff/Barber: برنامه کاری و نوبت‌های خودش
- Customer: ورود ساده، مشاهده خدمات/پرسنل/زمان آزاد، رزرو، لغو یا درخواست تغییر

## رزرو

- روزها و ساعات کاری
- break time
- مدت متفاوت هر خدمت
- availability پرسنل
- holiday و temporary closure
- جلوگیری قطعی از double booking
- وضعیت‌ها: pending, confirmed, completed, cancelled, no_show, rescheduled
- ثبت دستی نوبت و block کردن زمان توسط مدیریت
- نماهای روزانه، هفتگی و ماهانه

## محتوا

هر سالن اخبار، اطلاعیه‌های مهم، تصویر و گالری مستقل خود را دارد. اطلاعیه می‌تواند تاریخ انتشار/انقضا و حالت pinned داشته باشد.

## CRM ساده

برای هر مشتری: نام، موبایل، تاریخچه نوبت، آخرین مراجعه، نوبت بعدی، تعداد تکمیل/لغو/no-show و یادداشت داخلی.

## اعلان‌ها

رویدادهای اصلی: ایجاد، تأیید، رد، تغییر، لغو، reminder، تعطیلی سالن و اطلاعیه مهم. معماری باید push و SMS را قابل تعویض نگه دارد.

## UX

مسیر اصلی باید کوتاه باشد:

انتخاب خدمت → انتخاب آرایشگر → انتخاب روز → انتخاب ساعت → تأیید → ثبت نوبت

رابط باید فارسی طبیعی، RTL واقعی، سریع، مینیمال و مناسب استفاده روزانه روی موبایل باشد.
